# 印天乐个人主页

本地审核版。尚未发布到任何公网服务。

## 浏览方式

外景首页只呈现房屋和动画人物，不在下方排列个人资料。点击房门或“进入”按钮进入屋内；相册打开个人介绍与经历，书桌打开三个重点项目，奖杯柜打开成果，书架打开论文，照片墙打开活动照片，信箱打开联系方式。每个内容页面都有返回屋内入口。中英文切换保留当前页面，手机可使用房间下方的文字物件导航。

## 使用

保留本目录全部文件，通过本地 HTTP 服务或 GitHub Pages 访问 index.html。不能只单独发送 index.html，也不能直接双击 HTML 使用模块交互。若电脑安装 Python，可在本目录运行 `python -m http.server 4173`，然后打开 http://localhost:4173 。

## 文件

- index.html：主页入口。
- app.js：中英文内容、项目详情和成果分类。
- scene.js：可旋转的三维房屋与二维动画人物。
- room.js：室内物件、点击识别和页面入口。
- exploration.css：房屋入口、室内探索与独立内容页面排版。
- styles.css：电脑、平板与手机排版。
- assets：压缩照片、原音轨双语短片和二维动画人物。
- vendor：Three.js 与 OrbitControls，本地依赖及 MIT 许可。
